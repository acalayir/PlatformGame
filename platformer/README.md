# Zıpla Ada

Kısa, eğlenceli 2D platform oyunu — 16 seviye, 30 dil, dokunmatik ve klavye.

## Çalıştırma

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Tarayıcıda: http://127.0.0.1:8080/

## Dil

Sağ üstteki 🌐 düğmesi veya başlık ekranındaki Language — seçim `localStorage` içinde saklanır.
